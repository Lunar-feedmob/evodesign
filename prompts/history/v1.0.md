# EvoDesign Design Prompt

Version: v1.0

Generation: 001

## Objective

Create clear, calm and intentional interfaces where information hierarchy is more important than decoration.

## Design Principles

### 1. Typography First

Typography should establish hierarchy before containers, borders or decorative elements.

### 2. Generous Whitespace

Whitespace is structural. Do not fill space simply because it exists.

### 3. Strong Hierarchy

A viewer should understand the primary message, secondary message and supporting detail without effort.

### 4. Restrained Containers

Do not put every section inside a card. Use cards only when they genuinely improve comprehension.

### 5. Restrained Color

Use a small, consistent palette. Accent colors should communicate emphasis rather than decoration.

### 6. Illustration With Purpose

Graphics should explain an idea. Avoid decorative illustrations that compete with content.

### 7. Editorial Composition

Prefer thoughtful spatial relationships over repetitive UI grids.

### 8. Mobile Readability

Layouts must remain understandable on narrow screens.

### 9. Accessibility

Maintain sufficient contrast, readable text sizes and clear interaction states.

### 10. Simplicity

Remove unnecessary visual elements before adding new ones.
